# 🏥 Sistem Pemilihan Ketua PMR Wira

## 📋 Deskripsi
Sistem pemilihan digital untuk pemilihan ketua PMR Wira SMKN 1 Pringgabaya Tahun 2026. Sistem ini dirancang dengan keamanan tinggi dan antarmuka yang user-friendly.

## ✨ Fitur Utama
- ✅ **Login Dual System** (Pemilih & Admin)
- ✅ **Token-based Voting** untuk keamanan
- ✅ **Anti-Double Voting** protection
- ✅ **Real-time Vote Tracking**
- ✅ **Admin Panel Complete** dengan semua fitur manajemen
- ✅ **Responsive Design** untuk semua device
- ✅ **Activity Logging** untuk audit
- ✅ **Vote Statistics & Charts**

## 🚀 Instalasi

### 1. Persyaratan Sistem
- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx dengan mod_rewrite
- Composer (optional)

### 2. Langkah Instalasi
```bash
# Clone repository
git clone https://github.com/username/pmr-election.git
cd pmr-election

# Set permissions
chmod 755 -R .
chmod 777 uploads/ (jika ada)

# Buka browser dan akses:
http://domain.com/pmr-election/install.php

# Ikuti wizard instalasi
